PANDUAN MENYIMPAN SCREENSHOT PROYEK:
====================================
Simpan file gambar / screenshot (format .png, .jpg, .webp) di dalam folder masing-masing proyek:

Contoh:
- public/projects/union-getah/screen1.png
- public/projects/union-getah/screen2.png
- public/projects/pos-ignatia/pos-screen.png

Cara panggil di file src/data/portfolioData.js:
screenshots: [
  "/projects/union-getah/screen1.png",
  "/projects/union-getah/screen2.png"
]
